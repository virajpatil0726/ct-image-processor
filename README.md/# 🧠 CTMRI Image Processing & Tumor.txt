# 🧠 CT/MRI Image Processing & Tumor Detector

![MATLAB](https://img.shields.io/badge/MATLAB-R2025b-orange)
![Field](https://img.shields.io/badge/Field-Medical%20Imaging-blue)
![Status](https://img.shields.io/badge/Status-In%20Progress-green)

A MATLAB-based medical image processing pipeline that loads CT/MRI 
scans, enhances image quality, detects organ boundaries, and segments 
regions of interest.

## 📊 Features
- ✅ CT/MRI image loading (DICOM support)
- ✅ Image enhancement (contrast, noise reduction)
- ✅ Edge detection (Sobel, Canny)
- ✅ Morphological operations
- 🔄 Segmentation (in progress)
- 🔄 Measurements and reporting
