# Project Summary & Reflection

## What I Built
A complete MATLAB-based medical image processing pipeline that loads 
CT/MRI scans, enhances image quality, detects organ boundaries, 
segments regions of interest, and measures them quantitatively — 
built as project for Medical Engineering.

## Why I Built This
As a Medical Systems Engineering student,
 I wanted hands-on experience with the tools and workflows used 
in medical imaging research. I designed and built this project on my 
own, as a self-directed way to learn them in practice.

## What I Learned
- MATLAB fundamentals — matrices, loops, functions
- Image Processing Toolbox — imread, imshow, imhist
- DICOM file handling — dicomread, dicominfo
- Image enhancement — imadjust, histeq, medfilt2
- Edge detection — Sobel, Canny algorithms
- Morphological operations — dilation, erosion
- Segmentation — imbinarize, bwlabel, regionprops
- Automated region detection and measurement
- Professional project organization and GitHub workflow

## Challenges I Faced
- MATLAB syntax differences from Python (end keyword, indexing from 1)
- DICOM files too large for GitHub — learned .gitignore properly
- Understanding threshold selection for segmentation
- Connecting multiple processing steps into one clean pipeline

## What I Would Add Next
- Apply pipeline to real cardiovascular MRI data.
- Add 3D volume rendering of MRI slices
- Implement Otsu's automatic thresholding
- Build a proper MATLAB App Designer GUI
- Compare results across multiple patients

## Reflection
This project taught me that medical image processing is fundamentally 
matrix mathematics — and that MATLAB's strength lies in making that 
math intuitive and visual. I now understand why companies like 
Siemens, Philips and DLR use MATLAB as their primary imaging tool.
